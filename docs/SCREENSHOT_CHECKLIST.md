# HustleMap Screenshot Checklist

When capturing screenshots to complete the README and documentation, use the following guidelines:

## 1. Dashboard View
- **Filename:** `docs/screenshots/dashboard.png`
- **Location:** Navigate to `/dashboard`
- **Recommended Size:** Desktop (e.g., 1440x900)
- **Sample Data Needed:** Populate the dashboard with at least 5 jobs in different states (Applied, Interviewing). Ensure the Recharts graphs have enough data points to look interesting.
- **Placement:** README.md (Product Tour)

## 2. Job Pipeline (Kanban)
- **Filename:** `docs/screenshots/pipeline-kanban.png`
- **Location:** Navigate to `/jobs` (Kanban view mode)
- **Recommended Size:** Desktop (e.g., 1440x900)
- **Sample Data Needed:** Jobs distributed across Applied, Interview, Offer, Rejected columns.
- **Placement:** README.md (Product Tour)

## 3. Extension Capture in Action
- **Filename:** `docs/screenshots/extension-capture.png`
- **Location:** LinkedIn or Indeed job posting page
- **Recommended Size:** Browser window with extension popup open and selection box active.
- **Sample Data Needed:** A realistic software engineering job posting.
- **Placement:** README.md (Product Tour) & `CHROME_EXTENSION.md`

## 4. Interview Prep Hub
- **Filename:** `docs/screenshots/interview-prep.png`
- **Location:** Within a Job Details view, under the Interview Prep tab.
- **Recommended Size:** Desktop (modal or full page view).
- **Sample Data Needed:** Logged technical questions, difficulty rating, and notes.
- **Placement:** README.md (Product Tour)
